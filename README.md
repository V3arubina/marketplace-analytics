# Marketplace Analytics

Проект посвящен сбору, хранению и анализу данных онлайн-маркетплейса. 

В рамках проекта реализован ETL-пайплайн для загрузки данных из API в PostgreSQL, настроена ежедневная автоматическая загрузка данных, а также разработан интерактивный аналитический дашборд в Metabase.

---

## 📊 Дашборд Metabase

🔗 **Публичная ссылка на дашборд:** [Просмотр дашборда](http://89.108.78.196:3000/public/dashboard/69416cd8-995a-4e7f-9e83-c6c545798733)

Дашборд состоит из трех тематических вкладок:
*   **Общая аналитика** — основные показатели продаж, динамика выручки, количество заказов, средний чек, топ- и антитоп-товары, активный ассортимент.
*   **Клиенты и LTV** — анализ клиентской базы, DAU, WAU, MAU, Repeat Rate, Sticky Factor, Retention, RFM-сегментация и LTV.
*   **ABC-XYZ** — анализ ассортиментной матрицы, распределение товаров по ABC-XYZ-группам и оценка стабильности спроса.

 ## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository_url>
cd marketplace-analytics

### 2. Создание и активация виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# или .venv\Scripts\activate для Windows
```

### 3. Установка зависимостей

```bash
pip install requests pandas sqlalchemy psycopg2-binary python-dotenv
```

### 4. Настройка переменных окружения

Создайте файл .env в корневой директории проекта и укажите ваши данные для подключения к БД:

```bash
DB_HOST=your_host
DB_PORT=5432
DB_NAME=your_db
DB_USER=your_user
DB_PASSWORD=your_password
```

### 5. Создание схемы базы данных
Выполните DDL-скрипт для создания необходимых таблиц в PostgreSQL:

```bash
psql -U your_user -d your_db -h your_host -f src/ddl.sql
```

### 6. Загрузка исторических данных
Запустите скрипт для первичного наполнения базы данных историей:

```bash
python3 src/load_history.py
```

### ⏱ Автоматическая загрузка данных (Сron)
Для поддержания актуальности данных на дашборде настроена ежедневная инкрементальная загрузка. Скрипт выполняется автоматически через cron каждый день в 7:00 по московскому времени:

```bash
0 7 * * * cd /root/final_project_simulative && /root/final_project_simulative/.venv/bin/python3 src/load_one_day.py >> /root/final_project_simulative/logs/cron_daily_load.out 2>&1
Такой подход обеспечивает регулярное обновление метрик без необходимости ручного вмешательства.
```

### 📝 Аналитические отчеты
В папке reports/ представлены подробные бизнес-исследования:
1. Анализ ассортиментной матрицы и продаж (assortment_analysis.docx) Исследование структуры ассортимента, распределения выручки, выявление топ- и антитоп-товаров, проведение ABC-XYZ-сегментации, оценка активного ассортимента и скидочной политики.
2. Анализ клиентской базы и LTV (customer_base_ltv_analysis.docx) Детальный разбор активности пользователей, метрик удержания (Retention), повторных покупок, построение RFM-матрицы и определение факторов, влияющих на рост LTV.
